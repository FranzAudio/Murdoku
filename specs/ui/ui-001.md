## 5. Interaction Model and Component Specifications

### 5.1 Suspect Tray and Selection
- The suspect tray displays 6 character cards:
  1. **Lord Reginald Blackwood** (Vittima / Victim): Pre-marked with distinct crimson "V" badge (`assets/icons/victim-marker.png`).
  2. **Lady Beatrice** (Sospettato 1): Emerald feathered hat, pearls (`assets/characters/suspect-1.png`).
  3. **Colonnello Vance** (Sospettato 2): Military cap, handlebar mustache (`assets/characters/suspect-2.png`).
  4. **Professor Alder** (Sospettato 3): Ginger hair, round spectacles, bowtie (`assets/characters/suspect-3.png`).
  5. **Miss Scarlett** (Sospettato 4): Crimson dress, raven bob, ruby earring (`assets/characters/suspect-4.png`).
  6. **Dottor Croft** (Sospettato 5): Goatee, charcoal vest, pocket watch (`assets/characters/suspect-5.png`).
- Clicking an unplaced character card selects it (`aria-selected="true"`, glowing golden border).
- Clicking an already-placed character card highlights its cell location on the board.

### 5.2 Board Placement and Cell Actions (AC-6)
- **Place Person**:
  - With a suspect selected, clicking an empty cell places the suspect in that cell.
  - The cell renders the character portrait (`64x64px`), name tag, and room name tooltip.
  - The tray card switches to `placed` state (dimmed opacity `0.5`, badge showing cell coords e.g., `B3`).
- **Remove Person**:
  - Clicking a cell containing a suspect lifts/removes the suspect back to the tray.
- **Cell Elimination Mark ("X")**:
  - Clicking the "Modalità Segna X" toggle button OR right-clicking / long-pressing an empty cell places/removes an "X" mark (`assets/icons/mark-x.png`).
  - An "X" mark prevents accidental suspect placement until cleared.
- **Keyboard Placement**:
  - Pressing `1` through `6` selects the corresponding suspect from the tray.
  - Pressing `X` on a focused cell toggles elimination mark.
  - Pressing `Backspace` or `Delete` clears the focused cell.

### 5.3 Action Toolbar (AC-7, AC-9)
- **Annulla (Undo)**: Reverts the most recent placement, removal, or X-toggle action. Keyboard shortcut: `Cmd+Z` / `Ctrl+Z`. Disabled when history stack is empty.
- **Azzera (Reset)**: Prompts inline confirmation (*"Vuoi davvero svuotare la tavola?"*), then clears all placed suspects and X-marks, returning all suspects to tray.
- **Verifica (Check)**:
  - Evaluates current board against Murdoku rules (AC-2) and clues (AC-5).
  - If incomplete or violations exist: displays banner with specific counts (*"3 posizionamenti mancanti, 1 violazione riga/colonna"*).
  - If complete and correct: opens Victory Announcement modal naming the murderer (see Section 5.5).
- **Nuovo caso (New Case)**: Procedurally generates a fresh 6x6 case with unique solution (AC-1).

### 5.4 Row/Column Conflict Feedback (AC-8)
- Every row and column must contain exactly one person (rule 1).
- If two people are placed in the same row or column:
  - The row label (A-F) or column label (1-6) pulses red with warning icon.
  - The intersecting row/column line receives a subtle red glow (`--color-crimson-bg`).
  - Screen reader receives polite announcement: *"Conflitto: la riga B contiene più di una persona"*.

### 5.5 Clue Presentation and Scratchpad (AC-5, AC-11)
- Clues are displayed in cards grouped by semantic type:
  - **Stanze (Room membership)**: e.g., *"Lady Beatrice si trova nella Biblioteca."*
  - **Direzione (Cardinal position)**: e.g., *"Il Professor Alder si trova a Nord del Colonnello Vance."*
  - **Adiacenza (Orthogonal/Diagonal adjacency)**: e.g., *"Miss Scarlett è adiacente alla Serra."*
  - **Regole della Villa (Manor counts)**: e.g., *"Esattamente 2 stanze sono vuote."*
- Each clue card includes:
  - Category icon indicator.
  - Readable Italian text (with English switch available).
  - Scratchpad checkmark button: clicking marks the clue as resolved (strikes through text with muted gray style).

### 5.6 Victory and Solution Modal (AC-9)
- When the player completes the board correctly and clicks *"Verifica"*:
  - Modal overlay appears with celebration animation.
  - Identifies the murderer according to rule 2 (*"L'unico sospettato presente nella stanza della vittima è il colpevole"*).
  - Modal copy:
    > **CASO RISOLTO!**  
    > La vittima **Lord Reginald Blackwood** è stata assassinata nella **[Nome Stanza]**.  
    > L'unico sospettato presente nella stanza era **[Nome Sospettato]**, che è dunque il **COLPEVOLE**!  
    > *Tempo impiegato: 04:32 — Mosse: 18*
  - Primary button: *"Gioca un altro caso"* / *"Play another case"*.

## 7. Accessibility Specification (a11y)

1. **Keyboard Navigation & Order**:
   - `Tab` sequence: `[Nuovo caso]` -> `[Annulla]` -> `[Azzera]` -> `[Modalità X]` -> `[Verifica]` -> `[Suspect Tray: Chips 1-6]` -> `[6x6 Grid Cells]` -> `[Clue Cards]`.
   - Grid navigation: Arrow keys (`↑`, `↓`, `←`, `→`) move grid focus between cells `(row, col)`.
   - Keys on focused cell:
     - `Space` / `Enter`: places selected suspect or removes existing suspect.
     - `X`: toggles elimination "X" mark.
     - `Delete` / `Backspace`: clears cell contents.
     - `1` - `6`: directly places suspect 1 to 6.
2. **Visible Focus**:
   - All interactive controls feature a high-contrast focus outline: `outline: 3px solid #FBBF24; outline-offset: 2px;`.
3. **Screen Reader Announcements (`aria-live="polite"`)**:
   - Board cells include descriptive ARIA labels: `aria-label="Cella B3, Biblioteca, occupata da Colonnello Vance"`.
   - Conflicts announced immediately: `aria-live="assertive"` announcing row/column duplicate placements.
   - Check results announced clearly with counts and clues status.
4. **Color Contrast**:
   - Body copy on card surfaces: `#F3F4F6` on `#222733` -> Contrast ratio `11.4:1` (exceeds WCAG AAA `7:1`).
   - Secondary text: `#9CA3AF` on `#222733` -> Contrast ratio `5.2:1` (exceeds WCAG AA `4.5:1`).
   - Accent Gold: `#D4AF37` on `#12151B` -> Contrast ratio `8.1:1`.
5. **Reduced Motion**:
   - All animations (modal fade, celebration particles, pulse indicators) are suppressed when `prefers-reduced-motion: reduce` is detected.

## 9. Error and Retry Handling

- **Procedural Generation Failure**: If solver propagation fails to satisfy uniqueness (AC-4) after maximum retries (e.g., 50 attempts), generation stops cleanly, surfaces the error card, and allows instant retry without page reload.
- **State Preservation**: Board actions are held in an in-memory history stack (`undoStack`). Undo operations are idempotent and revert individual discrete actions (placement, removal, or mark).
- **Network / Offline**: Fully static client-side bundle. No fetch requests made for game assets or solver calculations; runs completely offline in all evergreen desktop and mobile browsers.
